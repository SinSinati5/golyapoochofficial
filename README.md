# Gol Ya Pooch Championship Archive

A seven-page static website. Open index.html to preview it offline.

## Pages

- index.html — overview and player cards
- freestyle.html — title podium, scores, historical victories, interactive rules
- traditional.html — podium, separate player records, latest result, traditional game explanation
- rankings.html — overall rankings, reasoning, and record notes
- sina.html, amir.html, efe.html — individual profiles and career records

## GitHub Pages

Extract this ZIP and upload its contents to the repository root, keeping assets intact. Commit to main. In Settings → Pages, choose Deploy from a branch, select main and /(root), and save. No build step or dependency installation is required.

## Records in this edition

Sina has 5 freestyle titles, Amir 2, and Efe 2. Traditional records are Sina 4–3 and Amir 6–4. The latest Sina 11–9 Amir result is assigned to traditional.

The two new Sina titles add to his existing 3. The new Amir and Efe titles each add to their existing 1. Three actual earlier traditional wins were added for Amir. The earlier hypothetical four-win scenario is excluded.

The original traditional score lists do not form one mirrored series. They remain independent player records. Unknown historical scores and opponents are explicitly marked. Career freestyle win percentages are unavailable because historical participation lists are incomplete.

Overall ranking is an editorial assessment of the documented record. Sina leads on individual titles. Amir's traditional wins provide the distinction over Efe in the overall title tie. Freestyle podium ties use points from the same four complete games.

## Editing

records.json contains the structured records and assumptions used for this edition. The HTML pages contain the displayed records. Update the JSON and affected HTML together when adding results. archive.js controls the mobile menu, rule explorer, and profile result filters. style.css controls layout and appearance.

assets contains the three AI-generated player portraits, the bundled display font, and its license.
